# Supported non-GST workflows

Source capability exists for ordinary purchases, sales/invoices, payments, customers, suppliers, batches, stock adjustments, ledgers, reports, audit logs, documents, and exports. The current source inventory does not by itself establish complete runtime acceptance.

The next verification campaign must select only workflows actually supported by current UI/actions and must reconcile stock, ledgers, and idempotency. Deferred features remain out of scope: e-invoicing/e-way bills, GST returns, ITC reconciliation, credit/debit notes, RCM, SEZ/UIN/deemed exports, multiple registrations, and unsupported UTGST/inclusive scenarios.
